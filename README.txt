# عرض تقديمي: تقنية المعلومات

## الملفات
- `index.html`: الشرائح ومحتوى العرض.
- `style.css`: التصميم والألوان والتجاوب مع الجوال.
- `script.js`: التنقل بين الشرائح.

## التشغيل
افتح `index.html` في المتصفح. استخدم السهمين أسفل العرض أو أزرار لوحة المفاتيح:
- السهم الأيسر أو Space: الشريحة التالية.
- السهم الأيمن: الشريحة السابقة.
- Home: البداية، End: النهاية.

## النشر حسب دليل التكليف
1. ارفع محتويات هذا المجلد إلى مستودع GitHub عام (Public)، واجعل `index.html` في جذر المستودع.
2. في Cloudflare اختر Workers & Pages ثم Create ثم Pages ثم Connect to Git.
3. اختر المستودع واترك إعدادات البناء فارغة، ومجلد الإخراج `/`، ثم Save and Deploy.

ملاحظة: غيّر خانتي إعداد العرض والمقرر في الشريحة الأولى قبل التسليم.
